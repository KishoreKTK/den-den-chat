# Character portraits

Optional. Add one image per character, named after the character, and the app shows it on the character's card and as the chat avatar:

- `sanji.png`
- `zoro.png`
- `vegapunk.png`
- `nami.png`
- `usopp.png`

`.png`, `.jpg`, `.jpeg` and `.webp` all work. Square images look best. A character without an image uses its generated emblem from `assets/art/`.

One Piece artwork is copyrighted. Only add images you have the right to use, especially if the app is deployed publicly.
